# Example contract

The Echo contract shared by the Paper example plugins and their Rust backend
(`examples/test-plugin-backend`). The examples consume MoonLightBridge like any application does:
Java code is generated by the published `ru.moonlightproject.bridge` Gradle plugin and Rust code by
the published `moonlight-bridge-codegen` crate.

- `proto/` holds the application schema.
- `options/` holds a copy of the published `moonlight/bridge/options/v1/options.proto`, which Rust
  builds need on their include path. The Gradle plugin bundles its own copy.
- `schema.lock` keeps field numbers and method IDs stable.
